## 🛠 Como executar

Clone o repositório:

```bash
git clone https://github.com/SEU_USUARIO/programacao_web_i.git
```

Entre na pasta:

```bash
cd programacao_web_i
```

Abra o arquivo `index.html` em seu navegador ou utilize a extensão **Live Server** no VS Code.
